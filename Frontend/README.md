# Frontend

This folder contains the SmartTransit React UI:

- app entry files in `index.html` and `src/main.jsx`
- public deployment assets in `public/`
- pages in `src/pages/`
- reusable components in `src/components/`
- data and API helpers in `src/services/`
- app styling in `src/styles.css`
- frontend tests in `tests/`

Use this folder when you need to change screens, forms, layouts, routes, styling or student/driver/conductor/admin UI behavior.

Production build output is generated at `Frontend/dist` by running `npm run build` from the project root.
